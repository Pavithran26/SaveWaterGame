# SaveWaterGame — Scratch Edition

This folder contains a Scratch 3 project for the SaveWaterGame concept.

## Open the project

1. Open [Scratch](https://scratch.mit.edu/projects/editor/).
2. Choose **File → Load from your computer**.
3. Select `SaveWaterGame_Scratch.sb3`.
4. Click the green flag.

## Controls

- **Left arrow:** Move the tank left.
- **Right arrow:** Move the tank right.
- Catch falling water drops with the tank.
- Every missed drop reduces `Lives`.
- Every caught drop increases `Score`.

## Included sprites

| Sprite | Purpose |
|---|---|
| Stage | Storm backdrop and game area |
| Tank | Player-controlled water tank |
| Water Drop | Falling clone that can be caught |

## Variables

- `Score`: increases when the tank catches a drop.
- `Lives`: starts at 5 and decreases when a drop reaches the bottom.

This is the first Scratch branch version. The next natural additions are milestone broadcasts at 25/50/75/100 points, thunder sounds, golden drops, pause/resume, and a dedicated game-over screen.
